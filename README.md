# E-Commerce Sales Analytics

## End-to-End Data Analytics Project

An end-to-end E-Commerce Sales Analytics project that analyzes sales transactions using Python, SQL, and Power BI.

The project follows a complete data analytics workflow, starting from raw data preparation and exploratory analysis to SQL-based business analysis and an interactive Power BI dashboard.

---

## Project Overview

The objective of this project is to analyze E-Commerce sales data and generate meaningful business insights related to:

- Revenue performance
- Order performance
- Customer behavior
- Product performance
- Category performance
- Regional sales
- Shipping status
- Return rate
- Monthly revenue trends

The project demonstrates how raw transactional data can be transformed into actionable business insights using data analytics tools.
